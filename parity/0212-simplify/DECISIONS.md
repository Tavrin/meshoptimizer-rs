# registered protocol simplify decisions

- Train 17 release was explicitly authorized in the continuation. Every build,
  proof and instruction campaign uses the installed <job-runner> wrapper via
  admit.sh, declaring 4 GB and PARITY_RUNNER_GPU=0. Wrapper reservations may adapt
  from retained job history; the declaration stays 4 GB.
- Keep the exact v0.2.11 baseline and the registered scalar M7 profile. Measure
  all 48 cells, all three arms and all three repetitions afresh. Reuse input
  blobs and the resident-loop protocol, never old instruction counts.
- Native std sqrt only handles nonnegative finite bit patterns. Every other
  operand delegates to the pinned portable backend, preserving signed zero and
  NaN payload/sign behavior. The full 2^32 sweep is mandatory. no_std keeps
  the original backend and memo.
- Removing the inline memo changes State's in-memory size, but Workspace's
  charged bytes count heap capacities. Exact std/no_std comparisons cover both
  Usage fields, cold/warm calls and both retention modes.
- Picker precharge uses the current index count as its bound. Each complete
  triangle is entered once and has exactly three charged corner visits; a
  capacity stop precedes the triangle and only reduces visits. No callback or
  numerical error occurs in the picker. The covered path settles its exact
  tally; insufficient work uses the original checked path. Worst-case meshes
  and the internal capacity test cover both paths.
- Keep finite checks: finite input values do not imply finite intermediate
  arithmetic. Defer new welding/hash algorithms and attribute rank accounting
  until their error, write and work equivalence can be established.
- Keep all failed attempts. The launcher parse failure preceded preparation;
  attempt1-test-compile and attempt2-test-format retain the initial successful
  arm builds and the failed proof receipts. The test compile/context and fmt
  repairs affect tests only. All final proofs restart on the final source;
  no rejected attempt contributes an accepted measurement sample.
- No API, version, SIMD, shared math backend, other family optimization,
  merge, tag or publication changes.

Final decision: retain the qualified gains. All three real-chain verdicts are
PARTIAL, no case exceeds 1.01, and the <=0.85 PASS target is not met. No
threshold relaxation or further unregistered optimization campaign.
