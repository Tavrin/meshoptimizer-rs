# Rust/Rust scratch driver

Retained r2 qualification binaries are reused, with SHA-256 checked before and after execution. identities.json binds each to its original full build receipt, parity fat-LTO profile (codegen-units=1, default-features=false, experimental, empty Rust flags/wrappers), and source hashes rechecked against git HEAD / afe803b. No rebuild or new compiler difference is introduced.

campaign.py imports the unchanged resident Paired protocol from parity/performance.py. Each case input is read verbatim from the r2 final frozen input archive; its digest must match both r2 frozen matrices. This includes the original cached topology for overdraw, API mode, attributes, target ratio and timing repetitions. Both backends are Rust. The resident driver performs exactly one untimed operation on startup: starting C then B is the one warm-up pair. It then receives exactly 12 triggers per backend. Alternating orders C,B / B,C produce repeating C B B C (ABBA) measured blocks. The original timing includes validation, API allocation/copies, scratch and algorithm, and uses 64 calls for tiny inputs and one otherwise. No clock-value retry or adaptive stopping is permitted. Each final response must contain exactly those 12 timing values and equal output bytes.

Parent and both resident children are pinned to logical CPU 8, as in the r2 frozen setup. All 204 cases run in a single campaign, under measurement admission; coordinator-requested pauses release admission after a fully completed case and resume the same campaign at the next case. No completed case is sampled again. Seed 20261025 is used only for the prescribed bootstrap analysis, 10000 pair resamples per case. Family bootstrap draws recompute medians within cases then the geometric mean; percentile 2.5/97.5 bounds are reported. Cases use lower bound >1.02; families use point estimate >1.02.

Absolute bars use r2/frozen-final-1/benchmark.json without new C++ timings, except the registered million/disconnected/allocating overdraw exemption. Parity and fuzz are cited from r2, not rerun.
