# Partition qualification

`REGISTRATION.md` fixes the workloads, arms, decision rule, and campaign limit. `ATTRIBUTION.md` records the pre-edit profiles. `REPORT.md` records the outcome and proof exits.

The exact observer links independently built baseline and candidate crates and compares result, count, assignments, usage, and the entire sentinel-filled caller buffer. It sweeps work and storage budgets and includes a seeded differential generator. The C++ driver and comparator use the same explicit little-endian case format and compare complete outputs against the pinned scalar reference. These are unpublished proof adapters; they do not alter the library API.

The LOD replay capture uses a private baseline source snapshot instrumented immediately before each partition call. A captured case is eligible only after the complete replay matches its existing reference output. Measurement uses the existing resident-loop comparison driver with a scratch-only adapter for those captured counts, indices, positions, and target. Its campaign records one finished case at a time and resumes without remeasuring completed cases. The raw inputs, output hashes, admission receipts, binaries, profiles and counter files are retained with the private run artifacts.
