# Security policy

## Supported versions

The foundation is unreleased. Security fixes target the current development
version; there is no published supported-version claim yet.

## Reporting a vulnerability

Use the repository's **Security** tab and choose **Report a vulnerability**
to open a private security advisory. Do not disclose vulnerabilities in a
public issue.

Include the input or reproducing program, crate version, features, target,
and resource limits. Relevant reports include panics, excessive work or
allocation on untrusted input, and exposed dependency vulnerabilities.
